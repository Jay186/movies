# AI 分镜脚本规范 v1（通用版）

> 出货口：**MiniMax H3 · Ref2VA（全参考模式）**
> 定位：把「分镜切割 / 画面质感 / 运镜美学」三件事从**手感**变成**可机读的判据**
> 通用性：零题材词表、零 IP 绑定、零「按题材判分流」；全部判据只吃结构量（时长 / 动作数 / 景别 / 朝向 / 色温 / 方向 / 配比）

---

## 0. 通用性铁律（最高优先级，违反即整份脚本不合格）

| 编号 | 铁律 | 判据（怎么算违反） |
|---|---|---|
| **G1** | **零题材词表**：规范、校验器、渲染器、示例里不得出现任何题材专属名词（地点名 / 物种名 / 道具专名 / 职业名）。 | 校验器对脚本正文做词表无关检查；规范文档内示例一律用 `@角色A` `@场景1` `@道具X` 占位 |
| **G2** | **判据必须是结构量**：任何「该不该拆镜 / 该给什么景别 / 该用什么运镜」的判断，只允许依据时长、动作数、主体数、空间数、状态改变、情绪强度档、配比计数。 | 出现形如「如果是打斗就…」「雪山场景要…」的条件分支 = 违反 |
| **G3** | **环境参数全部外置**：画幅、帧率、单次生成时长上限、模型容量表、语速常数，一律由全局配置注入，**不写进分镜脚本**。 | 脚本里出现 `9:16` `16:9` `1920x1080` 等尺寸字面量 = 违反 |
| **G4** | **容量表驱动，而非题材驱动**：一次生成能演几镜、一镜能演几个动作，由**模型容量表**（§2.6）决定，可随模型版本整体替换。 | 把容量写死进文案而不是常量表 = 违反 |
| **G5** | **可替换性**：换 IP、换画风、换语言、换模型，只需换「主体卡 + 风格锁 + 容量表」三样，规范与校验器一行不改。 | 需要改校验器代码才能换题材 = 违反 |

> 这条铁律的来由：平台既有 `A1/A2 全链零词表零正则判定` 的工程口径（见 `server/tests/sceneElements.test.mjs` 的【通用性】断言）。本规范与之同源，只是把口径从「要素/环境卡」扩到「整套分镜脚本」。

## 1. 层级模型：从剧本到节拍，五层

```
剧本 Script
 └─ 场次 Scene          同一时间 + 同一空间的连续叙事单元
     └─ 生成单元 Unit    ★ 一次 H3 Ref2VA 调用（可含 1..N 个 [Shot]）
         └─ 镜头 Shot    一个完整视觉任务
             └─ 节拍 Beat 一个时间戳上的动作（H3 的稳定演出颗粒）
```

### 为什么必须多一层「生成单元」

H3 Ref2VA 的 prompt 形态是：

```
[Shot 1] 无时间戳，开场镜
[Shot 2] At 00:09.000, ...
[Shot 3] At 00:15.000, ...
```

**一次生成可以演多个镜头**——所以「切割」是两级问题，而不是一级：

| 层级 | 决定什么 | 答错的症状 |
|---|---|---|
| **单元级切割** | 哪几个镜头交给**同一次生成** | 单元内镜号互串、前镜末帧接不上后镜首帧、主体漂移 |
| **镜头级切割** | 镜头边界在哪 | 一镜塞多拍（动作被模型丢弃）、或该拆的全景念关键台词（观众看不清） |

平台现有的 `storyboardRules.js` **只解决第二级**。本规范把第一级补齐。

## 2. 第一支柱：分镜切割

### 2.1 镜头级切割：四步算法（顺序不可换）

```
Step 1  写镜头任务句：{主体} 在 {空间} 里，为了 {目的}，产生了 {可见变化}，最后停在 {结束状态}
Step 2  切镜收益闸门：这次切镜至少拿到 8 项收益里的 1 项，否则合并
Step 3  负载闸门：过 §2.3 全部可数上限，超限先加时长、再拆镜
Step 4  拆后复核：末帧→首帧接得上吗？切点动作有没有被重做一遍？
```

**Step 1 的产出是内部草稿，不写进交付物**（防止「分析文字」污染画面描述）。但 `description` / `finalFrame` / 时间轴动作**必须围绕同一句任务句**，不能各写各的。

### 2.2 切镜收益闸门（8 项，至少 1 项）

| 编号 | 收益 | 举例（抽象） |
|---|---|---|
| B1 | 新主体 | 画面里出现了一个此前不在场的主体 |
| B2 | 新空间 / 新距离 | 主体移动到另一空间，或与对象的距离发生不可忽略变化 |
| B3 | 新视角 / 新景别承担信息 | 必须换成近景才看得见关键细节 |
| B4 | 新状态或动作结果 | 从未发生 → 已发生（门开了 / 物体碎了 / 人倒了） |
| B5 | 新危险 / 新发现 | 观众需要先看到，角色才能反应 |
| B6 | 独立情绪反应 | 另一主体对刚才的事产生独立反应 |
| B7 | 关系 / 决定改变 | 立场、承诺、同盟关系发生变化 |
| B8 | 台词信息推进 | 新信息 / 新决定 / 关系变化由台词带出 |

**反向闸门（必须合并）**：前后镜只是「同一主体 + 同一位置 + 同一件事」且无 B1~B8 任一收益 → 合并为一镜流。

**特殊保留**：画面相似但发生了新危险 / 新发现 / 新反应 / 新关系变化时，**保留切镜**，不得仅凭画面相似度合并。

### 2.3 负载闸门（可数口径，硬上限）

| 编号 | 规则 | 可数判据 |
|---|---|---|
| L1 | 动作密度 | 肢体动作动词数 ÷ 时长(秒) **≤ 0.6**；等价硬上限：5s≤3、6s≤3、7s≤4、8s≤4、9s≤5、10s≤6 |
| L2 | 单时间戳负载 | 每个时间戳 **≤1 主动作 + 1 伴随微动作**（呼吸/发抖/表情类） |
| L3 | 时间戳间隔 | 相邻时间戳间隔 **≥ 1 秒** |
| L4 | 时间轴节拍预算 | 时长扣除 Airlock 2 秒后，**每满 2 秒才可排 1 拍**（5s≤2 拍、6s≤2 拍、8s≤3 拍、10s+≤4 拍） |
| L5 | 因果事件上限 | 单镜 **≤ 2 环**因果链（因→果→果再算超标），第 3 环必须拆镜 |
| L6 | 多主体发力 | ≥2 个主体各自独立发力 → 按主体拆镜 |
| L7 | 台词挤压 | 同镜有台词时，动作数降到 1~2 个 |
| L8 | 长镜名分 | 时长 ≥8s 必须有明确意图（运镜推进 / 情绪沉淀 / 空间揭示），禁止「长镜+远景+固定+无台词」四无死画面 |
| L9 | 动作动词定义 | 只数**逐帧可见的肢体位移**（推拉撞甩跳摔走跑坐站转缩抖躲举放抱拍踢咬爬滚跌滑退拽凑跃冲踩钻攀压低挺起张开攥抵…）；「看 / 听见 / 想到 / 开口说」**不计数** |

**超限处理顺序（不可跳步）**：
1. 先问「这些动作是不是同一任务的连续链」——是 → **加长时长**（加到 动作数 ÷ 0.6 以上），不拆
2. 否 → 按**任务边界**拆镜（不是按动作个数拆）
3. 加时长与拆镜都不做 = 违反 L1

**合并的纪律**：并镜必须同步删掉中间态过程描写，只留任务链端点动作；合并后动作数仍受 L1 约束。「只并镜号不删动作」= 把两镜负荷压到一条时间轴上，出片更糊。

### 2.4 生成单元级切割（★本规范新增，三条全过才可合并）

| 编号 | 判据 | 不允许合并的情形 |
|---|---|---|
| **U1 时长容量** | 单元内 `Σ镜头时长 ≤ 容量表.单次生成上限`（默认 15s，见 §2.6） | 超出上限 |
| **U2 主体与空间连续** | 单元内镜头共享**同一主体集**与**同一空间**（最多一次同镜内完成的跨空间过渡） | 需要换空间、或需要引入新主体 |
| **U3 状态可串** | 前镜 `finalFrame` 能作为后镜首帧（Airlock 可成立）：位置 / 朝向 / 光照 / 道具状态连续 | 时间跳跃、空间跳跃、角色换装、道具状态突变 |

**单元切分的三个典型收益**（什么时候该合并）：
- 同空间内**同一任务的连续链**（发现→决定→走近）→ 合成一次生成，减少接缝
- **节奏需要一气呵成**的短促连续动作（三连快切，每镜 1.5-2s）→ 一次生成，剪切点由 `[Shot N] At MM:SS.mmm` 控制
- **对话正反打**（A 说 → B 反应 → A 再说）→ 一次生成，靠 Airlock 与视线锚保证不越轴

**单元不可合并的三条红线**：
- 单元内不得跨越两种光照常量（跨场光变必须单独成镜并在同镜内过渡，见 §3.3）
- 单元内不得出现角色进入/离开画面后空间重建立（视角重建立需新单元）
- 单元内不得包含两段独立音乐情绪（`non_diegetic_music` 是**单元级字段**，见 §5.4）

### 2.5 集级配比约束（拍法分布，防「一路平推」）

| 编号 | 约束 | 阈值 |
|---|---|---|
| D1 | 单一机位朝向占比 | ≤ 45% |
| D2 | 单一景别占比 | ≤ 40% |
| D3 | 单一运镜占比 | ≤ 30% |
| D4 | 推近（push in）全片次数 | ≤ 6 次 |
| D5 | 静止镜头占比 | ≤ 1/3 |
| D6 | 有台词镜头占比 | ≥ 1/4，且最长连续无台词 **≤ 5 镜** |
| D7 | 同类事件梗重复 | 同一灾难/动作梗全片 ≤ 2 次，第 3 次必须换花样或反转 |
| D8 | 开场钩子 | 首镜 **3 秒内**出现冲突/悬念/危险/异常之一；环境交代必须与钩子**同镜**完成 |
| D9 | 结尾镜时长 | ≥ `max(8s, 全片平均镜长 × 1.3)` |
| D10 | 节奏配比 | 钩子 1 镜 → 发展 3-5 镜 → 高潮 2-3 镜 → 卡点/升华 1-2 镜 |
| D11 | 对话镜连续数 | 连续纯对话 ≤ 2 镜，对话镜必须穿插动作或画面变化 |
| D12 | 静止对话单镜时长 | ≤ 6s |

**D6 与留白的优先级**：台词地板考核的是**全片密度**与**最长哑段**，不为凑数在情绪低点硬塞台词。留白镜的沉默优先于地板——密度在动作/冲突段补足。

### 2.6 模型容量表（外置常量，G4）

容量表是**唯一**允许出现具体数字的地方，且必须可整体替换：

```json
{
  "model": "MiniMax-H3-Ref2VA",
  "unitMaxSeconds": 15,
  "shotMinSeconds": 1.5,
  "shotMaxSeconds": 10,
  "airlockSeconds": 2,
  "beatsPerSecond": 0.5,
  "actionDensityPerSecond": 0.6,
  "maxCausalChains": 2,
  "speechCharsPerSecond": 4.5,
  "speechLeadInSeconds": 1.0
}
```

> 换模型 = 换这张表；换题材 ≠ 改这张表。

## 3. 第二支柱：画面质感

质感不是「加漂亮形容词」，而是**五个可声明、可校验的维度**：画风锁、光位、色温、材质、画面地理。

### 3.1 画风锁（零切换）

| 编号 | 规则 |
|---|---|
| Q1 | 全片所有镜头（含动作段/异变段/回忆段/梦境段）使用**同一画风**，任何镜头不得切换画风 |
| Q2 | 禁止出现风格切换词：写实、CG、三维、实拍、照片级、电影质感、`realistic / CGI / photoreal / hyperreal / live-action / 3D render` |
| Q3 | 剧情需要「变强 / 异变 / 爆发」时，**只能通过画面内容表达**（体量变化、毛发/材质变化、光效、环境反应），**不得借道画风切换** |
| Q4 | 「压迫感 / 重量感」等演出需求写成画面与动作语言（尺度对比、惯性、物理重量），不得写成画风词 |

### 3.2 光位-色温-氛围三维（缺一不合格）

每一镜的 `finalFrame.lighting` 必须**同时**声明两个部分：

| 维度 | 取值（枚举，外置于风格锁） | 写法 |
|---|---|---|
| **方向** | `from frame left` / `from frame right` / `from above` / `from behind` | 必填 |
| **色温** | `warm golden` / `cold blue` / `icy blue-grey` / `neutral daylight` …（风格锁定义） | 必填 |
| 氛围（选填） | 雾/尘/蒸汽/雨/雪/逆光轮廓 等环境介质 | 按需 |

**合格判据**：`finalFrame` 里出现形如 `warm golden light from frame left` 的**完整短语**。
只写色温不写方向 = **没声明**（光源位置会随参考图漂移，跨镜对不齐，校验也抓不到）。

### 3.3 光线常量：跨镜逐字复制，跨场同镜过渡

| 编号 | 规则 |
|---|---|
| Q5 | **光线常量复制铁律**：每个环境（主体卡里的 `lightingConstant`）在**本场第 1 镜**写出英文常量句，本场后续每一镜**逐字复制**，禁止改写为不同色温/方向/氛围词 |
| Q6 | **跨场光变必须在同一镜内完成过渡**：过渡镜同时保留旧光锚与新光锚（旧光仍在画面某侧 + 新光从另一侧进入），下一镜起才切到纯新光并沿用新的常量句 |
| Q7 | 直接「上镜全冷、下镜全暖」= 违反（观众对同一位置的光比有直觉，会觉得空间凭空跳了） |
| Q8 | 只有跨场或显式时间推移（如入夜）允许光线变化；同场相邻镜光线方向与色温必须一致 |

### 3.4 材质与氛围词（按「表面属性」分类，不绑题材）

描述画面质感时，从**表面属性**取词，而不是从题材取词：

| 属性维度 | 可声明的取值方向（示例，风格锁可裁剪） |
|---|---|
| 表面反射 | 哑光 / 缎面 / 高光 / 湿润反光 / 半透 |
| 表面纹理 | 细腻 / 粗糙 / 颗粒 / 纤维 / 裂纹 / 绒面 |
| 介质 | 无介质 / 薄雾 / 浓雾 / 浮尘 / 水汽 / 雨幕 / 雪粒 |
| 体积光 | 无 / 光束 / 轮廓光 / 逆光剪影 / 光斑 |
| 景深 | 深焦 / 中焦 / 浅景深 / 大光圈散景 |
| 画面颗粒 | 无 / 轻颗粒 / 胶片颗粒 / 笔触感 |

**判据**：一个镜头的质感声明只需 2~4 项（过多无意义，且会与参考图打架）；**同一场内相邻镜的质感声明不得相互矛盾**（如 A 镜"浓雾"、B 镜"无介质"且无剧情交代）。

### 3.5 色彩方案预设（按情绪映射，不绑题材）

整片选定一个方案，写入风格锁；各镜只声明**局部变量**（如某镜"暖点光"），不重复声明基调。

| 方案 | 基调 | 情绪指向 | 高光/阴影倾向 |
|---|---|---|---|
| 高对比冷调 | 冷 + 暗部压 | 紧张、危机、压迫 | 高光硬、阴影重 |
| 柔和暖调 | 暖 + 低对比 | 温暖、治愈、亲密 | 高光柔、阴影抬 |
| 低饱和灰调 | 低饱和 + 中对比 | 克制、写实、怅然 | 高光平、阴影实 |
| 高饱和明快 | 高饱和 + 高亮 | 欢快、活力、轻喜剧 | 高光溢、阴影浅 |
| 蜜色黄昏 | 暖橙 + 长影 | 升华、达成、余韵 | 高光金、阴影暖 |
| 冷蓝夜色 | 冷 + 点光 | 神秘、不安、悬念 | 高光点状、阴影蓝黑 |
| 单色去饱和 | 近单色 + 局部色保留 | 记忆、聚焦、情绪重击 | 高光淡、阴影同色 |

**判据**：一集内只允许一个方案；跨方案的切换（如黄昏→夜）必须由 Q6 的过渡镜合法承载。

### 3.6 画面地理（可机读、可跨镜校验）

| 编号 | 规则 |
|---|---|
| Q9 | **绝对画面坐标**：`finalFrame` 里每个可见主体必须声明画面侧位，取值 `at frame left` / `at frame right` / `at center frame`；禁止用相对坐标（`to her left` 有歧义：角色的左还是观众的左？） |
| Q10 | **视线锚物**：视线必须锚在具体对象（`gazes toward @角色B` / `gazes toward @道具X` / `gazes toward @场景1`）；禁止悬空视线（`looks into the distance` / `looks to the side`） |
| Q11 | **跨镜不越轴**：同一主体在相邻两镜的侧位不得凭空翻转；确需换侧必须是**镜内显式走位**（写进时间轴） |
| Q12 | **背景锚**：`finalFrame` 至少声明一个不动的环境锚点及其画面位置，作为跨镜空间一致性的基准 |
| Q13 | **换空间必须交代位移**：跨场时必须在下一场首镜的 `description` 与时间轴里写出位移过程（不能凭空换空间） |
| Q14 | **切点动作不重复**：上一镜 `finalFrame` 若把某主体停在动作进行中（`-ing`），本镜开头不得让同一主体把同一动作从零重做一遍；正确做法是把上镜末帧收在该动作**之前**（到位姿态），把动作整段让给下一镜 |

## 4. 第三支柱：运镜美学

### 4.1 官方运镜词汇（13 类 Motion type，H3 口径）

| # | Motion type | 中文对应 | 叙事功能 |
|---|---|---|---|
| 1 | `Static Shot` | 固定 | 让画面自己说话；情绪镜与对话镜首选 |
| 2 | `Push In` | 推近 | 逼近情绪 / 发现细节（全局 ≤6 次，D4） |
| 3 | `Pull Out` | 拉远 | 释放压力 / 交代空间 |
| 4 | `Zoom In` | 变焦推近 | 机身不动、焦段压缩（主观注视感） |
| 5 | `Zoom Out` | 变焦拉远 | 抽离 / 揭示环境 |
| 6 | `Pan Left/Right` | 横摇 | 跟随视线 / 揭示新元素 |
| 7 | `Truck Left/Right` | 横移 | 平行伴随 / 展开空间层次 |
| 8 | `Tilt Up/Down` | 摇上/摇下 | 揭示高度关系（体量、落差、天与地） |
| 9 | `Pedestal Up/Down` | 升降 | 改变视角高度（威压 / 渺小 / 全貌） |
| 10 | `Arc Shot` | 环绕 | 建立立体关系 / 仪式感 |
| 11 | `Tracking Shot` | 跟拍 | 与主体同速（移动段落专用） |
| 12 | `Shake Slightly/Strongly` | 轻微/强烈晃动 | 冲击 / 失稳 / 主观慌乱 |
| 13 | `POV` / `Roll` | 主观 / 滚转 | 第一人称 / 失控眩晕 |

**幅度与速度按需声明**：官方原则是「medium amplitude / normal speed 通常省略；只在**有意义**时才写」。中文语义明确时给显式幅度（如「推近」= `small amplitude at slow speed`）；语义中性者只写类型，交给模型按画面决定。

**未命中不兜底**：运镜词不在表内时**留空**，整句省略运镜从句。**绝不允许**兜底成 `static shot`——那是在向模型断言一个与意图相反的机位，比不写更糟。

### 4.2 运镜-情绪映射（选镜依据，不绑题材）

| 叙事需求 | 推荐运镜 | 节奏 |
|---|---|---|
| 平静 / 庄重 / 仪式 | 固定、缓慢推拉 | 缓慢 |
| 亲密 / 细腻 / 内心戏 | 缓慢推近至近景/特写 | 缓慢 |
| 紧张 / 压迫 / 不安 | 轻微晃动、快摇、短促跟拍 | 快 / 不规则 |
| 动感 / 爆发 / 冲击 | 强烈晃动、快速环绕、跟拍冲刺 | 快 |
| 开阔 / 史诗 / 格局 | 升降 + 大全景 | 中-慢 |
| 悬疑 / 眩晕 / 失控 | 变焦推拉、加速环绕、滚转 | 变速 |
| 纪实 / 真实 / 第一人称 | 手持跟随、POV | 自然晃动 |
| 发现 / 揭示 / 惊喜 | 缓推至关键细节 | 慢-中 |

### 4.3 运镜三条硬约束

| 编号 | 规则 | 判据 |
|---|---|---|
| M1 | **一镜一主运镜** | 单镜只承载一个主运镜动作；禁止「推近+横摇+上摇」三段塞一镜 → 拆镜或选一个 |
| M2 | **运镜必须有动机** | 每个运镜能对应一句叙事动机（推近=逼近情绪/发现细节；拉远=释放压力/交代空间；横摇=跟随或揭示；环绕=展示全貌/空间关系）。**无动机运镜**（为动而动的 `slow push in`）= 违反 |
| M3 | **动作即运镜** | 主体做发力动作（追逐/撞击/跃起/扑抱类）时，运镜必须配合动作语义（跟拍/环绕/晃动）；**禁止用固定机位让动作死在画面里** |

### 4.4 机位朝向（7 类，与平台 `camera_angle` 同口径）

`正面` / `侧面` / `正侧` / `背面` / `过肩` / `俯拍` / `仰拍`

| 编号 | 规则 |
|---|---|
| M4 | 每镜必须声明机位朝向（六/七选一，由风格锁裁剪），**单镜内朝向统一**，禁止混搭（显式转身动作除外，且转身须按 L1/L6 拆镜） |
| M5 | 朝向必须与运镜语义一致：出现「顺着视线 / 过肩 / 背对 / 望向画面深处 / 盯着背影」时，朝向只能是 `背面` 或 `过肩`，禁止 `正面` |
| M6 | 分镜图的构图朝向必须与 `camera_angle` 一致；主体描述中**不得出现该朝向看不见的特征**（背面镜禁止写正面专属特征） |

### 4.5 拍法节奏（集级，与 D1~D5 同源）

- 景别节拍：**全景/远景交代空间 → 中景建立关系与动作 → 近景/特写承担情绪**（同一场内至少 2 种景别）
- 朝向节拍：`侧面 ↔ 正面/背面/过肩/俯拍/仰拍` 轮换；横向调度段落最易一路「侧面+跟拍」，必须主动打断
- 运镜节拍：`跟拍 ↔ 固定/推近/拉远/横摇/环绕/升降` 轮换；**情绪镜与对话镜优先固定**（让画面自己说话），跟拍留给真正的移动段落
- 推近是强调手段，全片 ≤6 次——用到第十次就不叫强调了

## 5. 参考主体体系（Ref2VA 专用）

### 5.1 四类参考标签（官方口径）

| 标签 | 语义 | 本规范里的用法 |
|---|---|---|
| `<Subject N>` | 可复用/可修改的**可见内容**（角色、环境、道具、服装、特效） | 角色 / 环境 / 道具 一律走 `<Subject N>`；**主体卡**一一对应 |
| `<Picture N>` | 作为**具体帧锚**的参考图（首帧/关键帧/尾帧/构图锚） | 只在两种情形单列：首帧锚、分镜规划锚；**仅用于定义角色/场景/外观的图不单列**，写进对应 `<Subject>` 定义里 |
| `<Video N>` | 整片级关系（被编辑源片 / 续接起点 / 节奏结构来源） | 无源片时不用 |
| `<Audio N>` | 独立音频或音轨（音色 / 音乐风格 / 节拍 / 对白内容） | **音色参考必用**：`<Audio 1> is the voice-timbre reference for <Subject 1> (S1).` |

**编号纪律**：标签一旦分配，含义在六段中保持一致；`<Video N>` 与 `<Audio N>` **各自独立编号**，不同序号不表示不是同一源。

### 5.2 主体卡（SubjectCard）

每个参考主体一张卡，三类字段必须齐：

```json
{
  "id": "sub-01",
  "kind": "character | environment | prop | style | voice",
  "name": "@角色A",
  "refAssets": [
    { "type": "picture", "url": "…", "provides": "appearance" },
    { "type": "audio",   "url": "…", "provides": "voice-timbre" }
  ],
  "lockPhrase": { "zh": "…", "en": "…" },
  "forbiddenFeatures": ["正面专属特征（供背面镜排除）"],
  "lightingConstant": "（environment 专有）warm golden light from frame left",
  "notes": ""
}
```

| 编号 | 规则 |
|---|---|
| R1 | `lockPhrase.en` 在同一主体的**所有镜头逐字复用**，禁止同义改写（这是跨镜一致性的唯一锚） |
| R2 | `forbiddenFeatures` 用于 M6：背面/侧面镜必须据此排除看不见的特征 |
| R3 | `kind=environment` 必须带 `lightingConstant`，且本场后续镜头逐字复制（Q5） |
| R4 | `kind=voice` 必须绑定 `(Sx)` 口语编号，编号按**目标视频实际发声顺序**分配，一经分配不得重排 |

### 5.3 单元级参考图分配策略（★本规范新增）

一次生成最多挂 5 张参考图时，按**固定优先级**分配：

| 优先级 | 用途 | 标签形态 |
|---|---|---|
| 1 | **环境锚**（本单元空间，构图与光照基准） | `<Subject>` + 首帧锚时单列 `<Picture>` |
| 2 | **在场角色**（每个画面可见角色一张） | `<Subject>`（含 `lockPhrase.en`） |
| 3 | **关键道具**（本单元有状态变化或被持有） | `<Subject>` |
| 4 | **上一镜末帧 / 尾帧锚**（接缝连续性） | `<Picture>`（自然语序引用：`the shot begins from <Picture N>`） |
| 5 | **音色参考**（有台词时必挂） | `<Audio>` |

| 编号 | 规则 |
|---|---|
| R5 | 角色**逐一挂锁**：画面中出现的每一个角色都必须有 `<Subject>` 定义与外观锁定，**不得**用「no other character present」之类表述替代 |
| R6 | 参考图**不超额**：超出上限时按上表优先级裁剪，被裁剪项必须在 `retention_analysis` 里降级为 `weak_reference` 或删除标签（不得留悬空标签） |
| R7 | 环境图与角色图**不同帧**：不得把「角色+环境」合成图当环境锚（视角塌陷根因） |
| R8 | 末帧锚只在**需要接缝**时挂（第二镜起）；首镜不挂末帧锚 |

### 5.4 音频层与音乐（单元级字段）

| 编号 | 规则 |
|---|---|
| A1 | `overall_soundscape` 是**单元级**字段：只写环境音与物理音；对白/演唱/与具体镜头同步的音效**留在 detailed_description** |
| A2 | `non_diegetic_music` 只写「角色听不到、仅观众能听」的配乐；无配乐写 `N/A` |
| A3 | 有配乐时必须写**乐器 + 速度 + 动态走向**（例：`A restrained solo-piano score at a slow tempo, with sustained low cello underneath and no swell.`） |
| A4 | **声弧连续**：相邻单元的音乐情绪不得无转折硬跳变；平静段与紧张段之间的切换必须有剧情转折支撑，或写明渐变意图（渐强/渐弱/骤停/柔和下来） |
| A5 | **音乐文本语言统一**：全片统一一种语言撰写，禁止中英混排（混排会让音乐生成模型理解不稳定） |
| A6 | **该静就静**：情绪低点的单元 `non_diegetic_music` 写 `N/A` 或「骤停」，让观众听到呼吸与环境音——沉默本身就是情绪 |

### 5.5 台词与音色

| 编号 | 规则 |
|---|---|
| V1 | **台词完整铁律**：凡画面/剧本中有对白的镜头，必须输出该镜**全部**台词句，一字不漏；禁止漏句、只留一句、合并两个角色的台词 |
| V2 | 台词对象 `{character, tone, text, startTime}`；`startTime` 用**全片绝对秒** |
| V3 | **开口校验**：`镜内开口偏移 + 台词估时（语速 4.5 字/秒）+ 1 秒 ≤ 本镜时长` |
| V4 | 不确定该镜该不该有对白时，**宁保留不写 null**（H3 只念 `<d></d>` 内台词，漏了就是整片没声） |
| V5 | 对白/歌词在 prompt 里写在 `<d>[语言] …</d>` 内保留原文；其余部分一律目标语言（英文），**任何字段不得输出其他语言**（未命中的语气词直接丢弃，不回传） |
| V6 | 说话人编号 `(S1)(S2)…` 按实际发声顺序分配并全程复用；`retention_analysis` 里**不写** `(Sx)` |

### 6.1 三层对象

```json
{
  "meta":     { "styleLockId": "…", "capacityTable": "…", "language": "zh", "notes": "" },
  "subjects": [ /* SubjectCard × N，见 §5.2 */ ],
  "units":    [ /* GenerationUnit × N，见 §6.2 */ ]
}
```

### 6.2 生成单元

```json
{
  "unitId": "u01",
  "sceneId": "s01",
  "shots": [ /* Shot × 1..N */ ],
  "budget": { "targetSeconds": 15, "shotCount": 3 },
  "referencePlan": {
    "subjects": ["sub-01", "sub-02"],
    "pictures": [ { "ref": "pic-01", "role": "first-frame" } ],
    "audio":    [ { "ref": "aud-01", "role": "voice-timbre", "speaker": "S1" } ]

  "overallSoundscape": "（zh 草稿；出片前由渲染器译为目标语言）",

```

### 6.3 镜头卡（与平台 `shots` 表一一映射）

| 字段 | 类型 | 必填 | 判据来源 | 平台对应列 |
|---|---|---|---|---|
| `shotNumber` | string | ✓ | 场次-镜号 | `shot_number` |
| `duration` | number | ✓ | L1/L4/L8、D8/D9/D12 | `duration` |
| `shotType` | enum | ✓ | D2、4.5 景别节拍 | `shot_type` |
| `cameraAngle` | enum | ✓ | M4/M5/M6、D1 | `camera_angle` |
| `cameraMovement` | enum | ✓ | M1/M2/M3、D3/D4 | `camera_movement` |
| `taskStatement` | object | ✓（内部） | Step 1，**不输出** | — |
| `description` | string | ✓ | 画面内容（人读） | `description` |
| `beats[]` | array | ✓ | L2/L3/L4、§7 四段式 | （进 `integrated_multimodal_description`） |
| `finalFrame` | object | ✓ | Q9~Q14 | `final_frame` |
| `dialogue[]` | array | 条件 | V1~V4 | `dialogue` |
| `actionNote` | string | 选填 | 动作补充说明 | `action_note` |
| `shotAssets` | object | ✓ | R5、§5.3 | `characters` / `scene_assets` / `prop_assets` |
| `soundEffects` | string | 选填 | A1 | `sound_effects` |
| `transitionIn` | enum | 选填 | §7 转场矩阵 | — |
| `continuityFrom` | string | 条件 | U3、R8 | `continuity_url` / `keyframe_url` |

### 6.4 节拍（Beat）四段式

每个节拍必须写全四段，缺任一段即视为该道具/动作「无约束」（会被模型自由发挥）：

```json
{
  "at": "00:04.000",
  "actor": "@角色A",
  "action": "（主动作）",
  "manner": "（动作方式：缓慢/轻柔/猛然…，与剧本强度副词逐字对应）",
  "finalState": "（该动作结束时物体/主体的稳定状态）",
  "material": "（材质确认：不变/未损）",
  "negations": ["（否定约束：不倒下、不消失、不位移…）"]
}
```

**强度副词忠实铁律**：剧本里的强度副词（瞬间/突然/猛地/死死/飞快/拼尽全力）必须**按原强度**落到目标语言，禁止稀释成「缓慢/轻柔」——模型严格照副词节奏演，稀释了就演成慢动作。

## 8. 交付物与工作流

```
剧本(zh)
  │  ① 本规范 §2 切割算法（人/LLM 执行）
  ▼
分镜脚本 JSON  ← 唯一事实来源（schema/shotcard.schema.json）
  │  ② node tools/lint_storyboard.mjs 分镜.json      ← 确定性校验，零 AI 花费
  │  ③ 修正至 0 Error
  ▼
  │  ④ node tools/render_h3_ref2va.mjs 分镜.json --out ./out
  ▼
五份交付物：
  ├─ 分镜工作单.md        人读：镜号/时长/景别/机位/运镜/画面/台词/音效/转场
  ├─ h3_prompts.txt       ★ 喂 H3：每单元一段六段式英文 prompt（直接粘贴）
  ├─ h3_prompts.json      机读：六段结构化，便于平台入库
  ├─ voiceover.md         配音稿：按全片绝对秒的台词时间轴
  └─ lint_report.md       校验报告：逐条判据结论
```

**工作流纪律**：
1. 先出 JSON，再出交付物——不要手写交付物（手写必与 JSON 漂移）
2. 校验 0 Error 才可出片；`Warn` 需在报告里逐条写明「接受理由」
3. 生成顺序：**先首帧/关键帧图，再出片**；参考图未定稿不出片（参考图是 Ref2VA 的唯一真相源）
